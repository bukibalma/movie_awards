IMDb import (one-time backfill)

From IMDb: go to Your Ratings (or any custom list), click the three-dot menu, then Export — it downloads a CSV. Upload it here, or paste the CSV content or a plain list of titles below.

Fully automatic option: drop the exported CSV into the imdb-import/ folder next to docker-compose.yml on your server — the app checks it every 5 minutes and imports on its own, no need to come to this page at all.

This is meant as a one-time backfill. For ongoing tracking, use Plex sync below — it has a real API, so newly watched movies sync automatically from here on, without needing IMDb at all.

Plex — automatic watched sync

Connect your Plex server and any movie marked watched there gets added to your watched list automatically, checked every 15 minutes. No manual export needed for this going forward — unlike IMDb, Plex has a real API for this.

Find your server URL (e.g. http://192.168.1.10:32400) and token: Plex web app → open any item → ⋯ → Get Info → View XML, and copy the X-Plex-Token value from the URL bar.

TMDb — posters & exact Radarr matching

Connect a free TMDb key to show posters throughout the app and resolve every film to an exact TMDb ID. Without this, the Radarr export sends bare titles and Radarr guesses the movie via its own search — usually fine, occasionally wrong for ambiguous or very common titles.

Free key: themoviedb.org/settings/api → request an API key (choose "Developer") → use the API Key (v3 auth) value.

OMDb — IMDb / Rotten Tomatoes / Metacritic ratings

Shows ratings on each film's detail page. IMDb blocks automated access to its own site, so this uses OMDb — a free, legitimate API that aggregates IMDb's rating (and Rotten Tomatoes/Metacritic) without scraping IMDb directly.

Free key (instant, by email): omdbapi.com/apikey.aspx
